Our Story

Built to fix a very manual problem

Before Umang Foundation, campaign updates lived in WhatsApp groups, donation records lived in registers, and volunteer sign-ups happened over phone calls. It worked — barely — until an NGO tried to run more than two campaigns at once.

This platform was developed to digitise that entire workflow: campaign publishing, volunteer registration, donation processing, event management and beneficiary communication, all inside one system that any partner NGO can plug into.

Mission

Make giving effortless and accountable

To provide a single, transparent platform where every rupee donated and every hour volunteered can be traced back to real, on-ground impact.

Vision

A connected network of community-first NGOs

To become the default operating layer for small and mid-sized NGOs across India — replacing registers and spreadsheets with one accountable system.

Problem We Solved

What the old, manual system got wrong

⚠

Low Functionality

Adding or removing a single record needed two or three staff members.

⌘

Manual Errors

Human-entered registers meant inconsistent, error-prone records.

⇄

Poor Portability

Registers couldn't travel between branches or be reported on easily.

🔒

Weak Security

Paper records had no access control — this system runs on authenticated logins.

Approach

Built the mixed way — top-down and bottom-up

Pages like the homepage and donation flow were designed top-down from the user's journey; shared components — the data models, admin views, and URL routing — were built bottom-up.

Front End

HTML, CSS & JavaScript

Every page you're viewing now — responsive, accessible, and built from scratch for this project.

Back End

Python with Django

Views, models, and URL routing handle campaigns, volunteers, donations and admin control.

Database

SQLite

Five core tables — contacts, donations, events, gallery and team — power the whole system.
